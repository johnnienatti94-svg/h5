# E-commerce Landing Page Widgets

Common e-commerce landing page widgets are editable blocks you add, arrange, and customize in a page builder. Availability depends on the platform, theme, and installed extensions.

## Widget Types

| Category | Widget type | What it displays or does |
|---|---|---|
| Header & navigation | Logo / header | Brand logo, menu, and account/cart icons |
| Header & navigation | Announcement bar | Short messages such as promotions or delivery information |
| Header & navigation | Search bar | Search for products or categories |
| Header & navigation | Category navigation | Quick links to product categories |
| Header & navigation | Sticky bottom navigation | Mobile shortcuts to Home, Catalog, Cart, and Account |
| Banners & content | Hero banner | Main campaign image with headline and button |
| Banners & content | Banner carousel / slider | Multiple swipeable promotional banners |
| Banners & content | Image / image grid | Single images or a group of clickable images |
| Banners & content | Video | Product demonstrations or promotional videos |
| Banners & content | Text / rich text | Headings, descriptions, and formatted content |
| Banners & content | Image with text | Image beside a description and action button |
| Banners & content | Button / call to action | Links to shopping, registration, or another page |
| Product browsing | Product grid | Products arranged in rows and columns |
| Product browsing | Product carousel | Horizontally swipeable product cards |
| Product browsing | Featured product | A prominent section for one selected product |
| Product browsing | Category / collection tiles | Visual shortcuts to groups of products |
| Product browsing | Tabbed products | Switch between product groups within one section |
| Product browsing | Brand showcase | Brand logos linking to their products |
| Product browsing | Recently viewed products | Products the visitor previously viewed |
| Product browsing | Recommended products | Products selected by rules or personalization |
| Promotions | Sale / deal section | Discounted products and promotional pricing |
| Promotions | Countdown timer | Time remaining before an offer ends |
| Promotions | Coupon / voucher block | Offers customers can copy or collect |
| Promotions | Bundle offer | Products sold together as a package |
| Promotions | Shoppable image | Lifestyle image with clickable product tags |
| Trust & information | Reviews / testimonials | Customer ratings, reviews, and feedback |
| Trust & information | Benefits / trust badges | Highlights such as warranty and secure payment |
| Trust & information | Payment options | Accepted payment methods or installment options |
| Trust & information | Shipping / returns information | Delivery and return policy highlights |
| Trust & information | FAQ accordion | Expandable answers to common questions |
| Trust & information | Store locator | Branch locations, opening hours, and directions |
| Engagement & support | Signup / lead form | Collect contact details or registrations |
| Engagement & support | Social media feed | Social posts or customer-generated content |
| Engagement & support | Floating chat / contact button | Quick access to live chat or messaging |
| Engagement & support | Popup / slide-in | Promotions, signup prompts, or announcements |
| Layout & footer | Section / container / columns | Group widgets and control page structure |
| Layout & footer | Spacer / divider | Adjust spacing or separate sections |
| Layout & footer | Footer | Contact details, policies, and useful links |
| Layout & footer | Custom HTML / embed | Add external content or custom functionality |

## Common Page Editor Controls

- Add, drag to reorder, duplicate, hide, and delete widgets.
- Edit text, images, links, colors, and backgrounds.
- Adjust columns, spacing, image ratio, and product count.
- Select products manually or automatically by category, tag, or rule.
- Set different layouts and visibility for mobile and desktop.
- Schedule sections for campaigns and preview before publishing.

## Site-wide Components

Header, footer, floating buttons, and popups are often managed as site-wide components rather than ordinary landing page sections.
